# Security reporting

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/drawmotive/textgraph-renderer/security/advisories/new).
This repository's private reporting feature was enabled and verified on
2026-10-02.

Include the image digest or service/SDK version, platform, minimal reproduction,
and expected impact. Remove credentials and unrelated private data. Do not post
sensitive details in public issues. Ordinary bugs belong in the
[TextGraph issue tracker](https://github.com/drawmotive/textgraph/issues).
